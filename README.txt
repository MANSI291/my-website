# CyberWise – Cyber Safety Learning Website

## Project Description
CyberWise is a Flask-based web application that teaches users about cyber ethics and online safety.

## Features
- Cyber safety lessons
- Online cyber ethics quiz
- Student registration and login
- Individual quiz results with marks and percentages
- Admin login to view all students' quiz results

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run Locally
1. Open Command Prompt in the project folder.
2. Run `python app.py`.
3. Open `http://127.0.0.1:5000` in your browser.

## Main Files
- `app.py` – Flask application
- `templates/` – HTML pages
- `static/style.css` – Website styling
- `database.db` – Database for accounts, questions, and results
